# 한국인 패치

한국 플레이어를 위한 마인크래프트 클라이언트 편의 모음.

- **제작자** — Hyper spruce
- **라이선스** — MIT
- **로더** — Fabric (Fabric API 불필요, jar 하나만 넣으면 됩니다)
- **지원 버전** — Minecraft 26.1 ~ 26.2 (단일 jar)
- **런타임** — Java 25

## 기능

### 첫 실행 준비 (한 번만)

모드를 처음 켤 때만 동작하고, 그 뒤로는 사용자가 바꾼 걸 되돌리지 않습니다.

- 게임 언어를 한국어로 설정
- 서버 목록에 `hyperf.kr` 추가
- 채팅 열기 키를 `T` → `Enter` 로 변경 (이미 다른 키로 바꿔 뒀다면 건드리지 않음)

### 한글 입력 (IME)

- **한글 상태에서 이동이 막히는 문제 해결.** 글자를 칠 자리가 있을 때만 IME 를 켭니다. 원인은 OS IME 가 키 입력을 먼저 가로채 `WASD` 가 게임에 도달하지 않는 것이었습니다.
- 채팅을 닫으면 조합 중이던 글자와 조합창이 함께 사라집니다.
- 조합창이 입력 커서 옆에 붙습니다.

### 한국어 검색

창고·크리에이티브·레시피북 검색창에서 동작합니다. 바닐라 검색이 아무것도 못 찾았을 때만 끼어들어, 기존 검색 동작은 그대로입니다.

- **초성** — `ㄱㄱㅇ` → 곡괭이
- **영타** — `ckaskan` → 참나무 (한/영 전환을 깜빡했을 때)

### ESC 화면

- **폰트 설정** (좌측 상단)
- **스크린샷 폴더** — "버그 제보하기" 자리
- **서버 목록** — "플레이어 신고" 자리

### 서버 목록

접속한 채로 다른 서버의 상태를 보고 그대로 갈아탈 수 있습니다. 바닐라 멀티플레이어 화면을 그대로 상속해 생김새와 동작이 같습니다. 접속을 고르면 지금 서버에서 완전히 나간 뒤 대상 서버로 붙습니다(동시 접속 없음).

### 간소화 F3

```
FPS : 60
X : -264.9
Y : 64.9
Z : -1308.6
방향 : 서쪽
바이옴 : river (강)
플레이 시간 : 1시간 23분
```

바닐라 45 종 대신 이 일곱 줄만 나옵니다. 끄려면 설정에서 `debugScreen.simplified` 를 `false` 로 두세요.

### 폰트 교체

컴퓨터에 **설치된 폰트를 자동으로 찾아** 목록에서 고릅니다. 폴더에 파일을 넣을 필요가 없습니다. 고른 폰트는 리소스팩보다 우선 적용되고, 그 폰트에 없는 글자는 바닐라 글꼴로 넘어갑니다.

## 설정

`config/koreanpatch/config.json`

| 항목 | 설명 |
|---|---|
| `search.choseong` | 초성 검색 |
| `search.latinToHangul` | 영타 → 한글 해석 |
| `debugScreen.simplified` | 간소화 F3 |
| `font.enabled` / `font.fontFile` | 폰트 교체 |
| `font.scale` | 글자 크기 배율 |
| `playTimeTicks` | 누적 플레이 시간 (20 틱 = 1 초) |

## 빌드

```bash
./gradlew build
```

`gradle.properties` 의 `test_mods_dir` 로 지정한 폴더에 jar 이 자동 설치됩니다. 비워 두면 복사하지 않습니다.

## 26.1 과 26.2 를 한 jar 로 지원하는 방법

26.x 는 게임이 난독화 없이 배포되므로 매핑도 리맵도 없습니다. 따라서 두 버전에 모두 존재하는 심볼만 쓰면 jar 하나로 둘 다 돌아갑니다.

문제는 26.2 에서 화면 관리가 `Minecraft` 에서 `Minecraft.gui`(`Gui`) 로 옮겨간 것 하나뿐이었습니다 — `Minecraft.setScreen` 과 `Minecraft.screen` 필드가 사라졌습니다. 이건 `compat/McCompat` 이 런타임에 흡수합니다.

컴파일은 지원 범위의 가장 낮은 버전(26.1.2)에 대고 합니다. 높은 쪽으로 컴파일하면 26.1 에 없는 심볼이 바이트코드에 박힙니다.

믹스인 대상(`Minecraft.tick`, `PauseScreen.init`, `FontManager.createFontSet`, `FullTextSearchTree`)은 두 버전에서 시그니처가 같은 것만 골랐습니다. `Minecraft.onGameLoadFinished` 는 파라미터 타입이 달라져서 쓰지 않았습니다.

## 참고

기능 아이디어는 koreanify, Caxton, HQSimpleF3 를 참고했으나 **코드는 전부 직접 작성했습니다.** 세 저장소의 소스는 사용하지 않았습니다.
